Exercise 6 - Notes

Task: element-wise product of two 10,000 x 10,000 matrices (C[r][c] = A[r][c] * B[r][c]). This is not matrix multiplication.

Key points:
- The x coordinate selects the column and the y coordinate selects the row:
    col = blockIdx.x * blockDim.x + threadIdx.x
    row = blockIdx.y * blockDim.y + threadIdx.y
- The matrices are stored as flat row-major arrays allocated with malloc, so the index is idx = row * cols + col. Each matrix is 400 MB, so a local array like int A[10000][10000] would overflow the stack.
- Both dimensions need a guard (row < rows && col < cols), because the grid is rounded up and some threads fall outside the matrix.
- Threads per block: dim3 threadsPerBlock(32, 16) = 512 threads.
- Grid: 10,000 / 32 = 312.5 -> 313 blocks in x; 10,000 / 16 = 625 blocks in y. So the grid is 313 x 625 blocks (195,625 blocks).
- Total threads = 195,625 x 512 = 100,160,000, which is 160,000 more than the 100,000,000 elements, so the guard is needed.
